## What this session added on top

1. **Stripped the legacy 6/18 overtime fallback** in `SchedulingEngine.ts`.
   The `dayWindows` check now defaults to **non-overtime** when no shift
   window exists for that day — emitting a spurious "overtime" flag on
   a day with no shift was noise; if the day is genuinely unworkable
   the calendar fitness check upstream already rejected the placement.
2. **Replaced the stale `create_db_user.sql`** with a deprecation stub
   that points users to `create_db_user.sql.template` and
   `scripts/render-sql.mjs`. The plaintext password
   `'SysproScheduler123!'` is no longer in source.
3. **Documented this audit** (this file).

A `CpSatClient.ts` standalone was briefly drafted before discovering the
canonical `CpSatSchedulingEngine` already existed; the file was kept as
a deprecated re-export so any in-flight imports keep resolving.

## What's still genuinely outstanding

1. **Test coverage** — three new test files since Week 1 (calendar,
   undoRedoManager, SchedulingEngine, smoke). The roadmap target of
   ~25 backend + ~12 frontend tests isn't yet met. The big gap is
   `SysproDatabaseService` and `APSDatabaseService` — they touch SYSPRO
   directly and have zero tests.
2. **Hardcoded `.slice(0, 500)` pagination** at `App.tsx:3342` for the
   workcentre rows table still silently truncates with no UI badge.
3. **Per-resource availability windows are still empty** in the
   CP-SAT request payload (`CpSatEngine.ts:159`). Calendar enforcement
   for CP-SAT runs entirely against the unconstrained horizon today —
   the greedy path's calendar checks don't apply. Honest TODO; flag
   in `cp-sat/main.py` as a v1 limitation.
4. **App.tsx is still a god component** (~3,500 lines, ~50 useState
   hooks). The Zustand store proof-of-concept (P2 #41 in the roadmap)
   hasn't started. The Sprint suggestion was "land one small store
   first" — still the right move, just not done.
5. **No ADRs yet** (P3 #66). Big decisions like "CP-SAT as a sidecar
   not in-process", "ad-hoc migration runner vs Umzug", "react-scripts
   not Vite" — all undocumented except in chat threads.
